# kelas-melayu

เว็บไซต์บทเรียนรายวิชา **0001154 ภาษามลายูในชีวิตประจำวัน** (Malay Language in Daily Life)
สาขาวิชาภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ

## สิ่งที่มีในเว็บ

- แผนการเรียน 15 สัปดาห์ และบทเรียน 12 บทตาม มคอ.3 (TSU03) ภาคเรียนที่ 1/2569
- บทสนทนาพร้อมปุ่มฟังเสียง (ใช้เสียงอ่านของเบราว์เซอร์) และปุ่มซ่อนคำแปล
- ตารางคำศัพท์ บัตรคำ (flashcard) และคลังคำศัพท์รวมที่ค้นหาได้
- หลักภาษา สำนวนภาษา (Simpulan Bahasa) และวัฒนธรรมมลายู
- แบบฝึกหัดตรวจคำตอบอัตโนมัติ (เติมคำ เลือกตอบ จับคู่)
- เครื่องมือแปลงตัวเลข เวลา และวันที่เป็นภาษามลายู
- ใช้งานบนมือถือได้ มีโหมดมืด

## โครงสร้างไฟล์

```
index.html                  หน้าหลัก (โครงหน้าเว็บ)
assets/css/style.css        การจัดรูปแบบ สี ตัวอักษร
assets/js/course.js         ข้อมูลรายวิชา ผู้สอน ตารางเรียน เกณฑ์คะแนน
assets/js/lessons-01-06.js  เนื้อหาบทที่ 1–6
assets/js/lessons-07-12.js  เนื้อหาบทที่ 7–12
assets/js/app.js            โปรแกรมแสดงผล (ไม่ต้องแก้ไข)
```

## วิธีแก้ไขเนื้อหา

แก้ไขไฟล์ `assets/js/lessons-*.js` ได้โดยตรงบน GitHub (กดไอคอนดินสอ แล้ว Commit changes) เว็บจะอัปเดตภายในประมาณ 1 นาที

- บทสนทนา: `dialog: [["ผู้พูด", "ภาษามลายู", "คำแปลไทย"], ...]`
- คำศัพท์: `vocab: [{ g: "ชื่อกลุ่ม", items: [["คำมลายู", "ความหมาย"], ...] }]`
- แบบฝึกหัดเติมคำ: `{ type: "fill", title: "...", items: [{ q: "คำถาม", a: ["คำตอบที่ถูก", "คำตอบที่ยอมรับได้อีกแบบ"] }] }`
- แบบเลือกตอบ: `{ type: "mc", title: "...", items: [{ q: "คำถาม", o: ["ก", "ข", "ค"], a: 0 }] }` (a = ลำดับคำตอบที่ถูก เริ่มนับจาก 0)
- ครอบคำภาษามลายูในข้อความด้วย `<i>...</i>` เพื่อให้แสดงเป็นตัวเอียงสีเขียว
